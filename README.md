# Janela da bolsa 
<p>
  Criei esta janela para ter um pouco de pratica em API e JSON!
</p>
<p>
  Ela serve para pegar os valores das 3 principais Açoes como a: <strong> vale3, petr4, itub4 </strong>
  e mostra o resultado em uma janela <br>
  Ela mostra o Preço: Atual, Alto e Baixo ea Mudança em % (porcetagem)
</p> 
<br>

Para rodar use o comando abaixo para baixar as bibliotecas nescessarias:

```
pip install -r requirements.txt --no-deps
```

E depois rode usando o:

```
python bolsa.py ou python3 bolsa.py
```
